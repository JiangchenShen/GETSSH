# GETSSH 终端工作台

先读相邻的 `getssh-ui-foundations/SKILL.md`。参考图 2、4 将终端画布放在首位。上方用连续、紧凑的会话栏标明标签和当前主机；分屏以细线分隔。工作区和资产按需展开。文件、AI 和插件操作从实际具备能力的会话或已有入口访问。

外框与终端配色分开。保留 xterm 主题、行列尺寸、文字对比、焦点、命令输入和 TUI 全屏。连接、断开与身份都来自当前会话；CPU、进程表、命令编辑器等只在已有相关能力时展示。保留工作区切换、标签拖拽、分屏、独立窗口和原生标题栏。

检查连接后回主页再返回、分屏焦点、缩放、关闭或切换标签、窄窗，以及文件面板切换时终端不重新挂载。
