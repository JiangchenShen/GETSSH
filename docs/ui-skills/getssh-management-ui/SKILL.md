# GETSSH 管理界面

先读相邻的 `getssh-ui-foundations/SKILL.md`。参考图 5、6 的共同结构是清晰页头、短说明、单一主操作，随后是可扫描的表单或列表。设置用分类、分区标题和分隔行，连接编辑把目标和身份放在认证及高级选项之前；插件、工作区和 AI 的条目显示实际状态和动作。省去编号标签、重复标题和散落颜色。代码和路径用等宽字体。

能力留在原有页面。工作区管理资产与迁移；设置收拢应用安全、隐私和 AI 配置；AI 管对话与历史。命令中心维持搜索驱动的键盘工作流。参考中的代码片段、转发和监控只指导有相应能力的组件。

按面板宽度调整布局。窄时导航可横向滚动或转为顶栏，表单改为单列；字段名和操作保留可见焦点。检查保存、取消、失败、空数据和中文长文案。
