# GETSSH 主页与主机

先读相邻的 `getssh-ui-foundations/SKILL.md`。以参考图 1 的横向页头、窄导轨、主机列和开放地图为骨架。页头放 GETSSH 标志、一个搜索框、添加主机和当前工作区名称；已打开的标签从工作区名称处返回。主页导轨提供主页、主机管理，以及一组 AI、插件、设置和指令中心入口，底端是 Ocean Sentinel。文件和终端能力在实际会话里呈现。

主机列显示真实分组、系统图标、名称、等宽地址、推测国家和连接与编辑操作。连接中和失败与具体主机关联。右列用轻分隔线和列表相隔，呈现平面点阵地图。离线按 IP 推测地区；没有可信位置则显示未知，点位不表示在线。邻近亮点可合并，选择必须能定位具体主机。

窄窗里先列表后地图。检查空工作区、多个分组、相邻地图点、选中和连接失败。保持清爽首页，不恢复全局工具墙或快速连接表单。
